# Atmospore Pollen Forecasts

AI-driven global pollen and allergy forecasting service providing species-level forecasts (real-time plus up to 14-day) at ~28 km resolution, covering 25 species across trees, grasses, and weeds with multilingual metadata and defined risk thresholds.

- **Provider:** https://atmospore.com/
- **Documentation:** https://atmospore.com/api-docs
- **Base URL:** https://pollenapi.com

## APIs

- **Atmospore Pollen Forecast API** — REST API for species-level point and area pollen forecasts, top contributing species, and species metadata. API-key auth via x-api-key header; /v1/species requires no auth. Responses in grains/m³ with risk levels. (`https://pollenapi.com`)

> Public REST API at https://pollenapi.com/v1/* with a confirmed live OpenAPI 3.0.3 contract (JSON and YAML). An open-source MCP server (atmospore/atmospore-mcp, MIT) exists but runs locally over stdio (pip install atmospore-mcp, ATMOSPORE_API_KEY env) — it is NOT a hosted/remote HTTP or SSE endpoint, so it is not cataloged as an MCP property and does not count toward agent_native. It is also listed on the third-party Glama MCP directory. No llms.txt could be verified (fetch returned 'not accessible' rather than a definitive 404, so absence is inferred). No published agent skills, and no AsyncAPI/GraphQL/Postman contract found. Related Python client: atmospore/atmospore-python.

## Correction — enrichment pass 2026-08-09

The paragraph above is the original submission summary and is **wrong on two points**. Both were
re-probed live on 2026-08-09:

- **A hosted, remote MCP server does exist** at `https://mcp.atmospore.com/mcp`. A `tools/list`
  POST returned a well-formed JSON-RPC error (`-32001`, "Missing API key. Send
  `Authorization: Bearer ak_...` or `?key=ak_...`") — a live MCP endpoint behind API-key auth, not
  an HTML shell. It is documented for Claude Desktop, Cursor, Continue and ChatGPT Desktop at
  <https://atmospore.com/article/mcp>. The provider is therefore agent-native. The MIT-licensed
  stdio server at `github.com/atmospore/atmospore-mcp` is the local equivalent of the same
  four tools, not the only MCP surface.
- **`pip install atmospore-mcp` does not work** — there is no `atmospore-mcp` project on PyPI
  (404 on 2026-08-09). The published client library is `atmospore` (the async Python client).

Also confirmed: **no llms.txt** (`/llms.txt` returns 403 on atmospore.com, 404 on pollenapi.com),
**no A2A agent card** on any host, and **no AsyncAPI, GraphQL, webhook or Postman surface**. The
YAML rendering of the OpenAPI at `/v1/openapi?format=yaml` is served but **does not parse**; use
the JSON at `/openapi.json`.

Note also that `atmospore.com` serves a single-page-app catch-all: every unrouted extensionless
path returns HTTP 200 with ~35 KB of homepage HTML. A 200 from that host is not evidence a page
exists.
