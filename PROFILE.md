# Atmospore Pollen Forecasts

AI-driven global pollen and allergy forecasting service providing species-level forecasts (real-time plus up to 14-day) at ~28 km resolution, covering 25 species across trees, grasses, and weeds with multilingual metadata and defined risk thresholds.

- **Provider:** https://atmospore.com/
- **Documentation:** https://atmospore.com/api-docs
- **Base URL:** https://pollenapi.com

## APIs

- **Atmospore Pollen Forecast API** — REST API for species-level point and area pollen forecasts, top contributing species, and species metadata. API-key auth via x-api-key header; /v1/species requires no auth. Responses in grains/m³ with risk levels. (`https://pollenapi.com`)

> Public REST API at https://pollenapi.com/v1/* with a confirmed live OpenAPI 3.0.3 contract (JSON and YAML). An open-source MCP server (atmospore/atmospore-mcp, MIT) exists but runs locally over stdio (pip install atmospore-mcp, ATMOSPORE_API_KEY env) — it is NOT a hosted/remote HTTP or SSE endpoint, so it is not cataloged as an MCP property and does not count toward agent_native.
